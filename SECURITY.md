# Seguridad

Biblioteca Académica es un proyecto académico. No se ofrece garantía de endurecimiento para producción ni proceso de respuesta con SLA.

## Reportar un problema

No publique credenciales, datos de estudiantes, capturas de sesiones ni detalles explotables en issues públicos. Si el repositorio de destino habilita el reporte privado de vulnerabilidades de GitHub, úselo. Si no está habilitado, contacte al mantenedor por un canal privado conocido antes de divulgar detalles técnicos; esta documentación no inventa una dirección de correo.

Incluya una descripción mínima, impacto observado, versión/commit afectado y pasos reproducibles que no expongan datos reales. No pruebe contra instalaciones ajenas ni contra datos de aula.

## Límites conocidos

Las notas de evidencia y brechas aceptadas están en [docs/verification.md](docs/verification.md). Una instalación de producción requeriría, entre otros controles, HTTPS, credenciales de mínimo privilegio, copias de seguridad/restauración verificadas y validación específica del despliegue.
